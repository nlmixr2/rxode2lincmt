# Number of threads linCmtB() has run on (test hook)

Number of threads linCmtB() has run on (test hook)

## Usage

``` r
.linCmtBThreadsSeen(reset)
```

## Arguments

- reset:

  logical; when `TRUE` clear the record after reading it

## Value

integer count of the distinct thread slots linCmtB() ran on since the
last reset
